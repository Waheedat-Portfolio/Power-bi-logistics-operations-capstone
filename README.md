# Power BI Logistics Operations Capstone Project

## Project Overview

This project involved analyzing logistics operations data using Microsoft Power Query and Power BI.

The goal was to transform raw data into meaningful insights through data cleaning, data modelling, DAX calculations, KPIs, and interactive dashboards.

The project features two dashboards:

1. Driver & Fleet Operations Dashboard
2. Customer Performance Dashboard

The project demonstrates practical skills in data preparation, analysis, visualization, and business reporting.
