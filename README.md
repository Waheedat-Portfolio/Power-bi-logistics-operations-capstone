# Power BI Logistics Operations Capstone Project

## Project Overview

This project involved analyzing logistics operations data using Microsoft Power Query and Power BI.

The goal was to transform raw data into meaningful insights through data cleaning, data modelling, DAX calculations, KPIs, and interactive dashboards.

The project features two dashboards:

1. Driver & Fleet Operations Dashboard
2. Customer Performance Dashboard

The project demonstrates practical skills in data preparation, analysis, visualization, and business reporting.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Power BI Data Modelling

## Project Tasks Performed
- Cleaned and transformed logistics data using Power Query.
- Created data models for analysis.
- Developed DAX measures and calculated KPIs.
- Analyzed driver and fleet operational performance.
- Evaluated customer performance and delivery operations.
- Created interactive dashboards to present business insights.

## Dashboards Developed

### 1. Driver & Fleet Operations Dashboard
Analyzed:
- Driver on-time performance
- Miles per gallon (MPG)
- Revenue per mile
- Truck mileage and revenue
- Fleet utilization

### 2. Customer Performance Dashboard
Analyzed:
- Customer revenue
- Load volume
- On-time delivery performance
